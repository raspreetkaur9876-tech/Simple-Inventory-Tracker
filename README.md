# Simple Inventory Tracker

## Project Description
The Simple Inventory Tracker is an Excel-based project designed to manage and monitor product stock levels.

## Objective
To track inventory, identify low-stock products, and make stock management easier using Excel formulas.

## Tools Used
- Microsoft Excel
- IF Formula
- FILTER Formula
- Conditional Formatting

## Features
- Product inventory management
- Automatic stock status detection
- Low-stock identification
- Low-stock report generation
- Inventory summary

## How It Works
The project uses the IF formula to check product quantities against reorder levels. Products with low stock are automatically marked as "Reorder".

## Conclusion
This project demonstrates how Excel can be used for simple inventory management and rule-based stock tracking.
